# firma-graph

Firma is one machine, not a list of products. The Firma Order is the collective that builds it. This graph is how an agent learns the machine the way the team holds it: the same truths, the same words, the same look, the same posture. Read this file, then follow the links that matter for the task at hand. Each `[[name]]` is a file called `name.md` in one of the folders beside this file. Every node opens with a YAML description, so you can scan a folder before you read a file.

**Mission, verbatim:** "We build sovereign infrastructure for the frontier and the reach — restoring agency, dignity, and prosperity to the people the current systems were not designed for." See [[mission]].

## How to engage (read first)

- Say what is true and what it means. Firma is not selling. See [[stewardship-not-selling]].
- Plain words on every screen and in every doc. Locked nouns stay; invented shorthand goes. See [[plain-language]].
- Every number is a projection until a real deployment measures it. See [[numbers-are-projected]].
- Keep the words exactly. Casing is canon. Killed words never come back. See [[names-and-casing]] and [[killed-words]].
- Find the named canon file before deriving anything. See [[find-canon-first]].
- Fix the source, state the rule, never narrate the correction. See [[correct-dont-narrate]].
- Preview first. A live Firma surface changes only after an explicit go. See [[preview-before-live]].
- Borrow the insight from outside frameworks, keep our vocabulary. See [[canon-over-frameworks]].
- Decide the technical choices, then explain them plainly. See [[decide-and-explain-plainly]].

The full list lives in [[how-agents-engage]].

## The machine (truths/)

- [[one-machine]] — the six purposes every Firma drawing and document must make clear: one machine, people at the center, three rings, abundance outward, honest status, it has to do something.
- [[mission]] — "we build for the edges": the frontier and the reach, both first class.
- [[firma-order]] — Firma is an Order, not a company. Five Domains as a filter, the mottos, the operating entities.
- [[core-values]] — the seven Core Values, the Ethos as posture, the Code of Conduct.
- [[firmamint]] — Firma's own chain: compute and liquidity. Every -mint protocol is a layer on it. Publicly, "the compute substrate".
- [[basemint]] — the membrane between Base and firmamint. Never a bridge.
- [[atonemint]] — the economy that makes the system whole after every trade. FIG lives here. Convertors are its agentic layer.
- [[fig]] — the floating, thermodynamic currency. Money in pools or moving, never idle.
- [[elemint]] — fingerprints of real production, e(photon) e(H2O) e(Au) e(BTC), signed to a person, never a token. Vault claims are the tradeable piece.
- [[fragmint]] — your slice of the pie. Inheritable, never transferable. Fragmint capacity is the founding principle.
- [[embodimint]] — one person, one wallet, one record. The spindle every layer turns on. Six dimensions of standing.
- [[theos]] — the operating system of the Nation. You talk to theo; DNA governs it. theo faces humans, the Ambassador faces agents.
- [[dna-protocol]] — Trace, Pulse, Heartbeat, DNA Protocol. The conductor that catches drift. Firmagentics beneath it.
- [[edge-and-photon]] — Firma Edge (Realm, SeedBase, Haven, Compute) and Firma Photon (Photon, Ion+, Salt Ion+, Atmos). Edge Cache is the capital block.
- [[realm]] — the personal edge: Realm Node, Realm Node (mini), transit, cargo, and the Realm app. "Download Realm. Become a Node."
- [[seedbase]] — the seed of life planted in a place. A community Haven with every system a place needs. Lead with meaning, not mechanics.
- [[settlemint-and-place]] — the ladder a community earns, T0 to T4, and the place ladder Person to Nation of Heaven.
- [[earning-by-giving]] — hosts give excess to firmamint, the minting is the giving. "The power runs through firmamint." "The compute runs on firmamint."
- [[colony-intro-version]] — everything on Base today is the intro version that rolls over to firmamint. Never paint into a corner.
- [[numbers-are-projected]] — the rule for every quantitative claim, and when a number may become measured.

- Embodimint composite formula: two versions exist (six terms linear, five terms square-root). Allotmint runs the six-term linear one pending his call.

## Execution

When given a task: read the nodes the task touches, apply the words and the look, hold the posture, and produce the work in the plain register. When the task is a document, deck, or surface, run [[briefing-opening]], [[cta-honesty]], [[numbers-are-projected]], and [[killed-words]] as a checklist before you call it done. When something here conflicts with a file in the vault, the newer ruling wins and you say so in one line.
