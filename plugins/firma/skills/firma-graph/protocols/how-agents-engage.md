# How agents engage

The way agents engage is the same across every Firma surface, product, and document. This is the list; each line has its own node.

1. **Say what is true and what it means.** Firma is not selling. No "strongest argument", no "makes the case". Unflattering facts get equal billing. [[stewardship-not-selling]]
2. **Plain words on screens and in team docs.** Locked nouns stay; invented shorthand goes. [[plain-language]] · [[team-docs-plain]]
3. **Every number is a projection** until a deployment measures it. [[numbers-are-projected]]
4. **Honest calls to action.** Waitlist and join, never "Schedule Deployment" until deployment is bookable. [[cta-honesty]]
5. **Every briefing opens with the mission.** FIRMA LABS, we build for the edges, the frontier and the reach. [[briefing-opening]]
6. **Exact words.** Casing is canon; killed words never return. [[names-and-casing]] · [[killed-words]] · [[tribal-terminology]] · [[fans-is-future]]
7. **Find the named canon file first.** `wiki/X-protocol.md`, the hiring source of truth, the code structs. Grep code identifiers, not prose. [[find-canon-first]]
8. **Fix the source, state the rule, never narrate the correction.** [[correct-dont-narrate]] · [[killed-term-sweeps]]
9. **Preview before live.** A live Firma surface changes only after an explicit go. Saving a tracked file in a git-linked repo is a deploy. [[preview-before-live]]
10. **Borrow the insight, keep our vocabulary.** [[canon-over-frameworks]]
11. **Decide technical choices, then explain plainly.** No option menus. One step at a time in GUI walkthroughs. Workflows authored in plain "when X, do Y". [[decide-and-explain-plainly]]
12. **Draft confidently in the ethos voice.** Finish the page, then iterate. [[ethos-voice]]
13. **Fewer words, more visual** in walkthroughs and explainers. [[visual-docs]]
14. **Secrets go in the tool, never in chat or files.** [[secrets]]
15. **Phones are the surface; verify at 390px.** [[mobile-first]]
16. **Elevate, never replace.** Real assets stay. [[restraint]] · [[image-rules]]
17. **Write rulings into this graph the same session, then push.** [[keep-the-graph-current]]
18. **Never say "assemblies" on screen.** Systems. And never invent a Firma word; propose it, mark it PROPOSED, let Vision rule.
