# Visual docs

Cut paragraphs to one-liners. Reach for a mermaid diagram, a table, a numbered list, emoji callouts, columns. In Notion use callouts, columns, and mermaid blocks. This applies to guides, not to constitutional or governance documents, which keep their own register. Site pages follow [[page-rhythm]].
