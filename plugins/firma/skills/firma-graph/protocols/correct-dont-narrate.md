# Correct, don't narrate

A document that narrates its own corrections reads as machine-written and drags the reader through history they do not need. The fix belongs in the source file, not in a sentence about the source file.

Edit the handbook, wiki, or spec. State the rule in the new artifact as if it had always been true. In chat, one line: what changed, where. Related: [[killed-term-sweeps]] for historical mentions, [[plain-language]].
