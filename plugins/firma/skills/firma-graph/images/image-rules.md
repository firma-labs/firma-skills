# Image rules

- **Real assets over abstraction.** Curtis liked the real photography and branding on the Edge build; use the real renders in [[asset-library]] before drawing an abstraction. "use the firma edge images… there are so many in the files."
- **Dithers are a house element.** Pull real ones from the dither folder and show them at full strength as bordered image cells or split bands co-located with copy. Never bury them at low opacity under a scrim: "dithers sucked, couldn't see anything." Dark halftone family on dark grounds; cream ASCII family only on light cells.
- **Optimize first.** `sips -Z 1600 -s format jpeg -s formatOptions 82` (originals are 2.5–8.5MB). Embed as base64 for portable artifacts, or reference as sibling files so they travel.
- **Never strip real logos** or replace them with generic icons. See [[restraint]].
- **Keep the narrative photography** (people shots for CIK, Haven, Research): "some of the images are needed and should be kept."
- **Never reuse personal images.** The container with the Vergina Sun and IC XC NIKA cross is a personal image for one person's briefing. Skip watermarked license previews (`dithr-*.png`).
- **Blueprint and Edge diagrams** use the drafting grammar of [[firma-edge-design]]; the Firma globe mark sits in the header.
