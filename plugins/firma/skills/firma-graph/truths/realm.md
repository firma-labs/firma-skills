# Realm

| Layer | Name |
|---|---|
| The division and federation | **Realm** |
| Exterior wall-mount hardware | **Realm Node** (Home · Base · Container variants) |
| Wall-mounted slab form | **Realm Slab** |
| Indoor companion | **Realm Node (mini)** |
| Windshield or dash unit | **Realm Node (transit)** |
| Vehicle-bed unit | **Realm Node (cargo)** |
| Cross-device software | **Realm** (the app) |

Everything that runs Realm is a Node. Hardware Nodes are heavy, software Nodes are light, all federate as mesh peers. Anchor line: **"Download Realm. Become a Node."** Inference is the economic engine; mesh is the connective tissue. Vehicle Nodes carry encrypted carrier packs between mesh segments (delay-tolerant networking).

Capture kits attach to a Realm node: water (tank, meter, first-flush, cooling loop; Atmos on the wall), and the rest by need. Star Realm is connectivity under Realm, not orbital compute.
