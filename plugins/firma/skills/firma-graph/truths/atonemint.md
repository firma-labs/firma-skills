# Atonemint

Atonemint (at-one-ment: reconciliation, conversion) is the exchange, swap, and accounting protocol on [[firmamint]]. It has been the overarching name since 2023. It makes the system whole after every trade: the ledger, the reserve, the caps reconcile. Reconciliation is never forced on a person.

What it does: global swaps (FIG ↔ USDC and other currencies), local swaps between Settlemint coins and FIG, barter matching between elemints, compute accounting across the network, reserve tracking. [[fig]] lives here. e(xchange) is its marketplace surface. Its Sovereign Gateway is the Roca Bank charter in Puerto Rico.

**Convertors** (Curtis's spelling, never "Converter") are the agentic layers of Atonemint that run Commons Netting at every deployment. Named: **Photon Convertor** (kWh → e(photon) → cross-elemint) and **Compute Convertor** (TOPS·seconds → e(compute)). Structural parallels not yet named: Storage, Bandwidth, Water. The Photon Convertor's home is hardware, with a line to Atonemint. Use "orchestration layer" only to describe what a Convertor does, never as a name. The Compute Convertor runs the substrate; the Compute Reserve Engine (constitutional capital flow) builds it. Both exist.

The Atonemint origin is the 2021 download (QR, ATONEMINT, one dollar given returns more, the "righteous node"). Lead with it when telling the story. See [[fragmint]].
