# The intro version

Curtis: "we are building an intro version to all of this so it will need to roll over to firmamint and have stronger bonding curves for reputation etc. but for now we need to create the best system we can."

This is not a throwaway. Per [[basemint]], the Base surface being built now is the proto-basemint surface of the real thing.

**How to build:** design every reputation, ownership, and identity primitive so it can graduate on chain without a rewrite. Do not hardcode the scoring curve. Keep the reputation vector attestable (EAS on Base now, firmamint later). Do not foreclose [[fragmint]]. Do not bake Base-specific assumptions into domain code. Money in the apps is cents, never floats; every payment goes through the one rail; nothing reaches around the doors. Nothing may branch on human-vs-agent in payment or permission code.
