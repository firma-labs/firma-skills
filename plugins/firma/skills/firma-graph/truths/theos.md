# THEOS and theo

**THEOS** (all caps) is the operating system of the Nation: the agentic workstation OS. Not just an agent UI; a full workspace OS. "FirmOS" and "flowstation" are killed; the module is the **workstation**.

**theo** (always lowercase) is the agent people talk to, the human face of [[embodimint]]. "Send theo" is the universal primary action. DNA governs it; see [[dna-protocol]]. The governed spine is drawn vertically: Canon → DNA → THEOS → Firmagentics → theo.

**Agentic-native** at Firma is a posture (agents are coworkers; the substrate is on; 80% planning, 20% execution), a substrate (THEOS), and a loop (Spec → Crew → Judge → Compound). "The data model is the substrate": agents discover, read, write, navigate, and watch natively. No RAG wrappers, no screen scraping. The UI is a rendering of the substrate.

Rendering stack: AG-UI for the agent↔human edge (beside MCP for tools and A2A for agents), A2UI, json-render. AX (Agentic Experience) is Firma's preferred word for what others call UX; see [[ax-vocabulary]]. Firma's contribution is the covenant overlay on the open stack: the Phronema gate, DNA attestation, Embodimint standing on every rendered surface.

Design system for THEOS surfaces: the `theos-design` skill beside this graph. See [[design-index]].
