Read the DESIGN-SYSTEM.md and tokens.json files in this skill folder.

This skill covers the **Firmamint** brand design system:
- 20 brand colors (coral, crayola, vista blue, onyx, baby powder, vanilla, etc.)
- 6 gradients (primary coral-crayola-blue, soft pastel, warm sunset, golden fire)
- 9 font families (Gambarino headlines, Supreme body, Instrument Serif/Sans, etc.)
- 9-step spacing scale on 8pt grid
- 5-tier border radius scale (chip to pill)
- Shadow system with glassmorphism
- Motion tokens (visionOS spring easing)
- Night/Day theme modes

Key principles:
- Neuroaesthetic Minimalism — the design concept
- "Build Sovereign Systems. Together." — the tagline
- Warm gradients (coral/pink/blue) are the signature visual
- Supreme is the primary typeface, Gambarino for hero headlines
- Token Studio JSON syncs to Figma and code via GitHub

If the user invokes this skill, ask what they want to build or design, then use the tokens and brand guide to produce branded artifacts.
