# Firmamint Design System

> **The visual identity of Firma Labs and the firmamint ecosystem.**

Firmamint is the brand design system — the colors, typography, gradients, spacing, and visual language that define everything Firma builds. THEOS, Firma 0101, and all products inherit from this system.

## What's here

```
README.md              <- you are here
SKILL.md               <- Claude skill manifest
DESIGN-SYSTEM.md       <- full token reference and designer setup guide
tokens.json            <- Token Studio format, syncs to Figma + GitHub
```

## Token Studio Setup

1. Install [Token Studio](https://tokens.studio/) in Figma
2. Connect to GitHub: `firma-labs/firma-vault`
3. Token file path: `skills/firmamint-design-system/tokens.json`
4. Pull tokens, select Night or Day theme, design

## Figma

Variables are live in the [Brand Guide file](https://www.figma.com/design/oorII4hi6KsCBi6oxW3AXU/Firma-Labs--Brand-Guide):
- **Firmamint** collection — 20 brand colors
- **Theos** collection — 18 ambient/semantic colors (Night/Day modes)
- **Glass** collection — 15 glass material tokens
- **Spacing** collection — 9 values (4-64px)
- **Radii** collection — 5 values (chip to pill)

## Quick reference

**Brand colors:** Baby Powder `#FAF9F6` / Coral `#FA8C5D` / Crayola `#F6718D` / Vanilla `#FFE9A7` / Vista Blue `#84A7F7` / Onyx `#3F3F3F`

**Primary gradient:** Coral -> Crayola -> Vista Blue

**Typography:** Gambarino (headlines) / Supreme (body) / Instrument Sans (UI) / Instrument Serif (accent)

**Design concept:** Neuroaesthetic Minimalism
